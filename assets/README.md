# assets

こどもモードの背景ステージ（`css/stage.css` / `js/components/stage.js`）が使う画像。

| ファイル | 用途 |
|---|---|
| `idol-hero.webp` | 背景に立つ2人のイラスト（透過WebP） |

## 差し替え方

```bash
python tools/build-hero.py <元画像のパス>
```

長辺 920px の透過WebPに変換して `assets/idol-hero.webp` を上書きする。
そのあと `sw.js` の `CACHE` 版数を上げること（上げないと古い画像が残る）。

## 注意

- **透過PNGを元にすること。** 背景が白いと、画面下に溶け込ませるマスクが効かず、
  四角い板が浮いて見える。
- 生成AIの出力をそのまま置かない。だいたい 1〜3MB あり、4Gのスマホで初回表示が遅くなる。
- 画像が無くてもアプリは壊れない。`stage.js` が読み込み失敗を拾って、
  その層だけ畳む（グラデとキラキラは残る）。
