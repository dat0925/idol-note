# assets

こどもモードの背景ステージ（`css/stage.css` / `js/components/stage.js`）が使う画像。

| ファイル | 用途 |
|---|---|
| `idol-hero-1..3.webp` | 背景に立つイラスト3種（長辺920px） |
| `idol-hero-1..3-thumb.webp` | ホームの「はいけいをえらぶ」用サムネ（220px） |

娘がホーム画面から3種を切り替えられる。選択は `localStorage`（`idol:hero`）に持つ。

## 差し替え方

```bash
python tools/build-hero.py 元画像1.png 元画像2.png 元画像3.png
```

引数の順に `idol-hero-1` / `-2` / `-3` になる。本体とサムネを両方書き出す。
そのあと `sw.js` の `CACHE` 版数を上げること（上げないと古い画像が残る）。

## 注意

- **元データはコミットしない。** 1枚2〜3MBあり、publicリポジトリに置くと
  GitHub Pages から誰でも落とせてしまう。`.gitignore` で `idleimage*.png` を除外済み。
- 生成AIの出力をそのまま置かない。3枚で 7.5MB あり、4Gのスマホで初回表示が目に見えて遅くなる。
  変換後は合計 680KB（91%削減）。
- **透過PNGが望ましい**が、不透過でも構わない。
  `build-hero.py` が透過の有無を判定し、無い場合は外周を楕円状に飛ばして
  背景になじませる（そのままだと四角い板が浮いて見える）。
  透過済みの画像には掛けない（人物まで削ってしまうため）。
- 画像が無くてもアプリは壊れない。`stage.js` が読み込み失敗を拾って、
  その層だけ畳む（光とキラキラは残る）。
