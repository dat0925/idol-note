# ⭐ アイドルノート

なりたい自分に、まいにち一歩ずつ。
9歳の娘が「アイドルになりたい」という夢に向かうプロセスを、親子でいっしょに管理するアプリです。

同じデータを **こどもモード**（大きく・楽しく・続けられる）と
**おとなモード**（締切と段取りを管理する）の2つのUIで見ます。

## できること

| | こどもモード | おとなモード |
|---|---|---|
| 練習記録 | メニューをタップしてチェック、週スタンプ、連続日数 | 日付を選んで入力、ヒートマップ、履歴 |
| 目標 | 山のぼり表示で「いまここ」がわかる | 大目標→月→週の3階層ツリー |
| オーディション | — | 締切・書類/持ち物チェックリスト・結果 |
| カレンダー | — | 締切・本番・レッスン・練習日 |
| 成長の記録 | 写真とできたこと日記のタイムライン | ＋ 自己PR文の管理 |
| からだの記録 | — | 身長体重グラフ（既定で本人には非表示） |
| ごほうび | ポイントを貯めて交換をリクエスト | ごほうびの登録と承認 |
| 応援メッセージ | 届いたメッセージを読む | 書いて送る（即座に届く） |

## セットアップ

### 1. Supabase のテーブルを作る

Supabase ダッシュボード → SQL Editor で、`supabase/migrations/` の
ファイルを **0001 から順に** 貼り付けて実行します。

```
20260815_0001_idol_core.sql
20260815_0002_idol_parent_pin.sql
20260815_0003_idol_practice.sql
20260815_0004_idol_goals.sql
20260815_0005_idol_auditions.sql
20260815_0006_idol_portfolio.sql
20260815_0007_idol_gamification.sql
20260815_0008_idol_views.sql
20260815_0009_idol_storage.sql
```

### 2. 起動する

```bash
npm start          # http://localhost:3000
```

ビルドは不要です。静的ファイルをそのまま配信します。

### 3. 使いはじめる

1. おとなの方がアカウントを作り、**「家族をつくる」**
2. 設定 →「招待コードを表示」でコードを確認
3. お子さんが**別のメールアドレス**でアカウントを作り、**「招待コードで参加」**
4. おとなモードに初めて入るとき、4桁のあんしん番号（PIN）を決める

## 開発

```bash
npm test           # 純関数のテスト（node --test）
```

- バニラJS（ESモジュール）。**ビルドステップなし**。React/TypeScript/Tailwind は使いません
- コーディング規約と必須のセキュリティチェックは [CLAUDE.md](./CLAUDE.md)
- 設計の意図・テーブルとRLSの状態は [HANDOVER.md](./HANDOVER.md)

リリース時は `sw.js` の `CACHE` 版数を上げてください（上げないと古いJSが残ります）。

## プライバシーについて

- 写真は**非公開バケット**に保存され、表示のたびに期限つきURLを発行します。公開URLは存在しません
- 動画はアップロードせず、URLを記録するだけです
- オーディションの合否・親のメモ・費用・身長体重は、**お子さんのアカウントからは
  データそのものが取得できません**（UIで隠しているのではなく、DBの行レベルセキュリティで遮断）
- 「合格したから伝えたい」ときは、結果と伝える言葉だけを共有できます。親のメモは共有されません
